Summary:
========
unRTOS itself uses only 397 bytes total (176 flash + 221 RAM)
This represents approximately 0.02% of RP2040's 2MB flash and 0.08% of 264KB RAM.

The cooperative scheduler and unWire messaging system provide:
- Multi-core task coordination
- Lock-free inter-core messaging
- Timer-based scheduling
- Power-efficient operation with WFI
- Zero-copy message passing

All of this in under 400 bytes - demonstrating exceptional efficiency
for an embedded real-time operating system alternative.
